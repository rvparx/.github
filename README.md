# .github

Welcome to RV Parx! 🌲🚐

RV Parx builds modern, developer-first open-source tools designed to streamline, manage, and scale mobile living and outdoor hospitality experiences. Whether you are building reservation systems, site availability trackers, or custom IoT integrations for modern campsites, our software bridges technology with the great outdoors.

What We Build

Core Platform Engine: High-performance RESTful APIs and backend microservices tailored for site availability, dynamic pricing, and automated booking logic.

Smart Campsite Integrations: Lightweight IoT connectors for monitoring utility usage, site occupancy sensors, and automated gate access control.

Developer SDKs & Extensions: Flexible SDKs, CLI tools, and web components to help developers easily integrate RV park management data into custom apps or dashboards.

Tech Stack & Architecture

Languages: TypeScript, Go, Rust

Frameworks: Node.js, React, FastAPI

Database & Caching: PostgreSQL, Redis, PostGIS

DevOps & Cloud: Docker, Kubernetes, GitHub Actions

Getting Started

Looking to contribute or deploy an RV Parx module?

Explore the Repositories: Check out our pinned projects below to find core modules, API documentation, and SDK wrappers.

Setup Locally: Clone any repository and review its local CONTRIBUTING.md for environment setup guides and testing commands.

Join the Conversation: Report bugs, request features, or join ongoing design discussions directly through GitHub Issues and Discussions.

Community & Code of Conduct

We welcome contributors of all skill levels. Whether fixing a minor bug, writing technical documentation, or proposing major architectural improvements, your contributions are highly valued. Please ensure all interactions follow our community guidelines to keep RV Parx an inclusive and collaborative ecosystem.
